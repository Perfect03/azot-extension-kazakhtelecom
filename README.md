# Azot Kazakhtelecom Extension

<img src="https://kt.sequoia-api.lfstrm.tv/upload/3e4fac5b52da8776cb223c9c27f6d894.svg" height="100" alt="tv+" />

This extension for [Azot](https://github.com/azot-labs/azot) lets you to download movies, series and shows from the [tv+ Kazakhtelecom](https://tv.telecom.kz/) streaming service.
